# Nyx Wiki

Nyx is an open-source browser extension that applies a consistent, comfortable dark color theme across the web with zero white flash.

## Color Palette (Nyx Owl)

- **Background:** `#181a1b`
- **Text:** `#e8e6e3`
- **Customization:** Brightness, contrast, sepia, grayscale, and custom background/text overrides.
