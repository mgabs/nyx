# Security Policy

Any security vulnerability discovered in Nyx will be fixed as soon as possible with as minimal impact as possible when reported.

Please ensure you are always running the [latest version available](https://github.com/mgabs/nyx/releases).

Some web browser extension stores may have an older version currently published.

## Security Vulnerability Report

If you have discovered a security vulnerability, please report it via [GitHub Security Advisories](https://github.com/mgabs/nyx/security/advisories) immediately.
